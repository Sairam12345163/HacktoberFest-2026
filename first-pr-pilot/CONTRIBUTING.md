# Contributing

Thanks for helping! Keep changes small and focused.

1. Fork, then branch: `feat/<thing>` or `fix/<thing>`.
2. Use Conventional Commits (`feat:`, `fix:`, `docs:`).
3. Add or update tests in `tests/`; run `python -m unittest discover -s tests -v`.
4. Keep the runtime dependency-free (Python standard library only).
5. Open a PR describing the change and how you tested it.
