First PR Pilot

Paste a GitHub issue. Get a route for your first pull request, planned by a model running on your own machine.

Checking your local model...

A link like github.com/OWNER/REPO/issues/123, or the issue text.

Options

Leave empty to download the repo from the issue link automatically. Or enter a local folder or repo URL.

Ctrl+Enter also works.

From issue to first commit

You will get the files to open first, the project's own rules from CONTRIBUTING, a test plan, questions to ask the maintainers, and a pull request description ready to paste.

Everything is generated locally. Only the issue text is downloaded from GitHub.
